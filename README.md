# Abash web demo (GitHub Pages)

Single-page demo — all screens connected via hash routes (`#/`, `#/login`, `#/results`, …).

## Open locally

Double-click **`docs/index.html`** (or serve the `docs` folder). Stay on this one file; navigation is in-page.

## GitHub Pages

Settings → Pages → folder **`/docs`**. URL: `https://<user>.github.io/<repo>/`

## Routes

| Screen | Hash |
|--------|------|
| Home search | `#/` |
| Area picker | `#/area` |
| Results | `#/results` |
| Listing | `#/listing/l1` |
| Login / Signup | `#/login` · `#/signup` |
| Wishlist | `#/wishlist` |
| List a place | `#/list-place` |
| Owner dashboard | `#/dashboard` |
